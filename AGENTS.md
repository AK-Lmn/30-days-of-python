# Repository Rules: 30 Days of Python

## 1. Zero Comments in Code Files
- Do not write comments in any code or test files.
- Avoid `#` inline comments, block comments, and docstrings (`"""..."""`).
- Keep code clean, readable, idiomatic, and self-explanatory through meaningful naming and clean architecture.

## 2. Strict Daily Folder Isolation
- Always restrict all implementation, configuration, dependencies, virtual environments, and tests to the folder designated for that specific day (e.g. `01-devvault/` for Day 1, `02-file-organizer/` for Day 2).
- Do not create, modify, or delete files in the repository root or in other days' folders unless the user explicitly requests it.
